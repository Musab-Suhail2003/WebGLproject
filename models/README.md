## Models Folder Structure

    models/
    ├─ charizard-flying-animation/
    │  └─ source/
    │     ├─ Charzard Flying.glb       — flying animation (gameplay)
    │     └─ textures/                 — body/claw/toes/tongue PNG+EXR maps
    ├─ charizard.glb                   — standing model (intro + outro)
    ├─ golbat.glb                      — main antagonist
    ├─ magikarp.glb                    — the stolen meal
    ├─ pikachu.glb                     — standing Pikachu (intro + outro)
    ├─ pikachu-flying-on-charizard.glb — riding Pikachu (gameplay, on Charizard's back)
    ├─ rock.glb                        — collidable boulder obstacle (Quaternius CC0)
    ├─ cloud.glb                       — passthrough drifting clouds (Quaternius CC0)
    └─ tree.glb                        — tree foliage (trunk is procedural) (Quaternius CC0)
