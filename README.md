# Charizard's Chase — WebGL Mini-Game
### CSE352 Computer Graphics — Spring 2026 | Musab Suhail

A Pokémon-inspired browser game built with Three.js. Golbat steals Charizard's Magikarp — fly through an infinite obstacle field, catch Golbat, and cook the Magikarp with your own flame.

---

## Running Locally

```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`

---

## Controls

| Key | Action |
|-----|--------|
| A / D | Yaw left / right |
| W / S | Pitch up / down |
| Q / E | Roll left / right |
| ↑ / ↓ | Accelerate / decelerate |
| Shift | Boost (collect coins to charge) |
| Escape | Pause / skip cutscene |
